App: Fuelwise

Versão: v1.0.0

Build: debug local

Baixar APK (app-debug.apk)

Instruções

  1. Conecte o celular à mesma rede Wi-Fi do computador.
  2. Abra em http://IP_DO_COMPUTADOR:8080 no navegador do celular.
  3. Toque em Baixar APK.
  4. Permita a instalação de fontes desconhecidas quando solicitado.
  5. Abra o aplicativo. Para atualizar, basta repetir — os dados são preservados.
