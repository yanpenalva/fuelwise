# V0 — Local Prototype

## Scope

- Initialize the Flutter project.
- Implement a pure calculation domain.
- Validate user input.
- Build the minimum calculation and result interface.
- Add unit and widget tests.

## Exclusions

V0 does not include Drift, SharedPreferences, Riverpod, persistence, history, or a vehicle profile.

## Tasks

`V0-001` through `V0-009` cover project initialization, quality setup, domain types, validation, calculation, domain tests, form, result view, and widget tests.
