# ENV-006 — Environment Smoke Test

## Objective

Approve the environment before product implementation starts.

## Prerequisites

ENV-001 through ENV-005 are complete.

## Subtasks

- Use the initialized or minimal Flutter app.
- Run analysis and tests in the container.
- Generate a debug APK.
- Install it on a phone through host ADB.
- Open the application and record the result.

## Expected files

- `docs/planning/environment.md`
- `docs/device-testing/android-device-testing.md`

## Acceptance criteria

The environment is approved and SDK issues are resolved before V0 implementation.

## Tests

Perform the complete container-to-device smoke test.

## Out of scope

Product features beyond the smoke-test application.
