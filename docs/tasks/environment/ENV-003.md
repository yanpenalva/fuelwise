# ENV-003 — Create Docker Compose

## Objective

Provide a repeatable Compose workflow for development commands.

## Prerequisites

ENV-002 produces a working development image.

## Subtasks

- Create `docker-compose.yml`.
- Mount the project into the container.
- Add a Pub cache volume.
- Preserve `build/` and required artifacts.
- Define the `dev` service.
- Support shell, analysis, tests, and APK build commands.

## Expected files

- `docker-compose.yml`
- `docs/planning/environment.md`

## Acceptance criteria

`flutter analyze`, `flutter test`, and `flutter build apk --debug` run through `docker compose run --rm dev`.

## Tests

Run all three commands with a clean container.

## Out of scope

APK hosting and emulator orchestration.
