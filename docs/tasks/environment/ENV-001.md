# ENV-001 — Define Versions and Prerequisites

## Objective

Record the minimum development-tool versions and requirements.

## Prerequisites

Flutter with Android as the primary target has been selected.

## Subtasks

- Record Flutter and Dart versions.
- Record Android SDK and Build Tools versions.
- Define the minimum Android version.
- List Docker, Docker Compose, and disk requirements.
- Document applicable Linux, macOS, and Windows commands.

## Expected files

- `docs/planning/environment.md`
- `docs/hosting/local-apk-server.md`

## Acceptance criteria

- Required tools are identifiable.
- Versions are mutually compatible.
- No version is implicit.

## Tests

Review the documentation and manually verify the listed requirements.

## Out of scope

Automatic dependency installation and provisioning scripts.
