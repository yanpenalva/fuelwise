# ENV-005 — Configure Physical-Device Testing

## Objective

Document the host, container, and phone responsibilities for Android testing.

## Prerequisites

The host has a compatible phone and ADB installation.

## Subtasks

- Document Developer Options and USB debugging.
- Document host ADB verification with `adb devices`.
- Document APK installation and log collection.
- Keep USB and ADB outside the main container.

## Expected files

- `docs/device-testing/android-device-testing.md`
- `docs/planning/environment.md`

## Acceptance criteria

An APK generated in Docker can be installed with host ADB and diagnosed without USB access in the container.

## Tests

Connect a device, run `adb devices`, install an APK, and collect logs.

## Out of scope

Emulator execution inside Docker.
