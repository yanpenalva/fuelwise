# ENV-002 — Create the Development Docker Image

## Objective

Create a reproducible image containing Flutter, Dart, and Android build tools.

## Prerequisites

ENV-001 and the pinned versions are approved.

## Subtasks

- Create `docker/Dockerfile`.
- Install the pinned Flutter/Dart version.
- Install Android command-line tools, SDK Platform, and Build Tools.
- Accept Android licenses during the build.
- Configure `PATH`.
- Use a non-root user when practical.
- Validate `flutter doctor` in the container.

## Expected files

- `docker/Dockerfile`
- `docs/planning/environment.md`

## Acceptance criteria

The image builds without manual intervention and exposes Flutter, Dart, and Android tools without relying on local installations.

## Tests

Build the image and run `flutter doctor` inside it.

## Out of scope

Android emulator, USB, and ADB inside the container.
