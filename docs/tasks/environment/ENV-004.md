# ENV-004 — Standardize Commands

## Objective

Document a predictable command interface for the development workflow.

## Prerequisites

ENV-003 provides the Compose `dev` service.

## Subtasks

- Document dependency installation.
- Document analysis, tests, APK build, and cleanup commands.
- Avoid hidden machine state.
- Provide understandable failure diagnostics.

## Expected files

- `README.md`
- `docs/planning/environment.md`

## Acceptance criteria

The main workflow is documented, repeatable, and independent of local Flutter or SDK state.

## Tests

Run the documented commands from a clean checkout.

## Out of scope

CI/CD and remote automation.
