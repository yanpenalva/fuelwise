# V1-011 — Delete History

## Objective

Allow a user to delete one history entry safely.

## Prerequisites

The history screen and repository are available.

## Subtasks

- Add a delete action.
- Ask for confirmation.
- Delete by identifier.
- Refresh the list.
- Handle errors.

## Expected files

- `lib/.../presentation/`.
- `lib/.../infrastructure/` query/repository.

## Acceptance criteria

Only the confirmed entry is deleted and the list updates without restarting the app.

## Tests

Test confirmation, deletion, cancellation, refresh, and failure feedback.

## Out of scope

Delete-all and export.
