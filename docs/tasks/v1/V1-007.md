# V1-007 — Integrate the Profile into the Screen

## Objective

Use the persisted profile as optional form defaults.

## Prerequisites

Profile persistence and Riverpod composition are complete.

## Subtasks

- Load the profile.
- Fill consumption fields when available.
- Save only on explicit user action.
- Allow calculation without a profile.
- Preserve existing history snapshots.

## Expected files

- `lib/.../presentation/`.
- Profile integration tests.

## Acceptance criteria

The form handles loading, empty, success, and error states without making a profile mandatory for calculation.

## Tests

Test profile loading, explicit save, calculation without profile, and restart behavior.

## Out of scope

Multiple vehicles and automatic cloud backup.
