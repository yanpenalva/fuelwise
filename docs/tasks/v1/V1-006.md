# V1-006 — Compose State with Riverpod

## Objective

Compose replaceable providers and asynchronous application state.

## Prerequisites

V1-002, V1-004, and V1-005 are complete.

## Subtasks

- Add database and preference providers.
- Add profile providers.
- Add form and calculation controllers.
- Expose loading, success, and error states.

## Expected files

- `lib/.../application/`.
- `lib/.../presentation/` provider wiring.

## Acceptance criteria

UI state is composed through Riverpod, dependencies can be overridden, and failures are represented explicitly.

## Tests

Override providers in tests and verify each async state.

## Out of scope

Remote providers and synchronization.
