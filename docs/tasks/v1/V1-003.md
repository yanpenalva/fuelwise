# V1-003 — Create the Profile Domain

## Objective

Model and validate one vehicle profile.

## Prerequisites

V0 domain types and the V1 database shape are defined.

## Subtasks

- Add `VehicleProfile`.
- Add name and optional consumption values.
- Define validation and update behavior.

## Expected files

- `lib/.../domain/vehicle_profile.dart`.
- Profile tests.

## Acceptance criteria

The profile supports valid creation and update while preserving optional-value semantics.

## Tests

Test valid, empty, malformed, and invalid profile values.

## Out of scope

Multiple vehicles and synchronization.
