# V1-009 — Integrate Saving

## Objective

Save one history entry per valid user calculation.

## Prerequisites

V1-006 and V1-008 are complete.

## Subtasks

- Trigger one save after a valid calculation.
- Prevent duplicate saves.
- Show success and error feedback.
- Refresh the reactive history list.

## Expected files

- `lib/.../application/` calculation/history controllers.
- Integration tests.

## Acceptance criteria

Each valid calculation creates exactly one entry and the UI reflects the result of the save operation.

## Tests

Test success, failure, repeated submission, and list refresh.

## Out of scope

Bulk operations and synchronization.
