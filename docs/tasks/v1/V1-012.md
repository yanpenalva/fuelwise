# V1-012 — Refine UX

## Objective

Make the V1 flow clear and usable on small screens.

## Prerequisites

The complete V1 flow is functional.

## Subtasks

- Refine spacing and accessibility.
- Improve messages and scrolling.
- Support narrow screens.
- Make async states clear: branded loading state with the app motto while initial preferences load; explicit save and error feedback.
- Clearly indicate standard fallback behavior.

## Expected files

- `lib/.../presentation/`.
- Widget tests as needed.

## Acceptance criteria

The main flows are understandable, accessible, scrollable, and usable on narrow Android screens.

## Tests

Run widget tests and manual checks on a narrow physical device.

## Out of scope

New product features and visual redesign beyond V1.
