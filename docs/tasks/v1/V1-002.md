# V1-002 — Create the Drift Database

## Objective

Create the initial typed local database.

## Prerequisites

V1-001 and generated-code configuration are complete.

## Subtasks

- Add profile and history tables.
- Set schema version 1.
- Store decimals as text and dates in UTC.
- Add typed queries.
- Add database providers or access boundaries.

## Expected files

- `lib/.../infrastructure/database/`.
- Generated Drift files.

## Acceptance criteria

The database opens locally, exposes typed operations, and generates code without manual edits.

## Tests

Open an in-memory database and verify schema creation and basic queries.

## Out of scope

Schema migrations beyond version 1.
