# V1-005 — Persist the Preference

## Objective

Persist the standard/custom mode and custom threshold.

## Prerequisites

V1-001 is complete.

## Subtasks

- Use `SharedPreferencesAsync`.
- Store and load the mode.
- Store and load the custom threshold.
- Define defaults and invalid-value behavior.

## Expected files

- `lib/.../infrastructure/preferences/`.
- Preference tests.

## Acceptance criteria

Preferences load during initialization and survive application restarts.

## Tests

Test defaults, writes, reads, and malformed stored values.

## Out of scope

Cloud preferences and account settings.
