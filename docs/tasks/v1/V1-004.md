# V1-004 — Persist the Profile

## Objective

Read, create, update, and map the single local vehicle profile.

## Prerequisites

V1-002 and V1-003 are complete.

## Subtasks

- Implement profile reads.
- Implement creation and update.
- Represent the empty state.
- Map between Drift and domain models.

## Expected files

- `lib/.../infrastructure/` profile repository and mapper.
- Profile persistence tests.

## Acceptance criteria

Profile values survive application restarts and mapping preserves decimal values.

## Tests

Use an in-memory database for empty, create, read, and update cases.

## Out of scope

Profile sync and multiple profiles.
