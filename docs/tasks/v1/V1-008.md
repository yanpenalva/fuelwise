# V1-008 — Persist History

## Objective

Store a complete `CalculationHistoryEntry` after a valid calculation.

## Prerequisites

V1-002 and the V0 calculation result are complete.

## Subtasks

- Add the history domain model.
- Add the Drift/domain mapper.
- Store the complete result snapshot.
- Insert only after a valid calculation.
- Add an ordered query.

## Expected files

- `lib/.../domain/` history model.
- `lib/.../infrastructure/` history repository.

## Acceptance criteria

History is independent of later profile changes and is ordered predictably.

## Tests

Test insertion, complete snapshots, ordering, decimals, and UTC dates.

## Out of scope

Export, synchronization, and server-side history.
