# V0-004 — Implement Validation

## Objective

Validate user-entered prices and consumption values.

## Prerequisites

Domain types from V0-003 are available.

## Subtasks

- Accept comma and period decimal separators.
- Require prices greater than zero.
- Require consumption values greater than zero when provided.
- Distinguish optional empty input from invalid input.
- Create Portuguese user-facing messages.

## Expected files

- `lib/.../domain/` validation code.
- Validation tests.

## Acceptance criteria

Valid localized numeric input is parsed correctly and invalid input produces clear messages.

## Tests

Cover separators, empty optional values, zero, negative, and malformed input.

## Out of scope

Persistence and advanced form UX.
