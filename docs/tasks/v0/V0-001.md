# V0-001 — Initialize the Flutter Project

## Objective

Create the Android/Flutter foundation and validate application startup.

## Prerequisites

ENV is approved.

## Subtasks

- Create the Flutter project structure.
- Configure the application entry point, name, and identifier.
- Configure the `pt_BR` locale.
- Validate a debug run.

## Expected files

- Flutter project files.
- `lib/main.dart`.

## Acceptance criteria

The application starts successfully with the expected identity and locale.

## Tests

Run the app on an Android target and execute analysis.

## Out of scope

Calculation logic, persistence, and history.
