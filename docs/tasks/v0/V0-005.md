# V0-005 — Implement the Calculation

## Objective

Implement the approved ethanol-versus-gasoline recommendation rules.

## Prerequisites

Validation from V0-004 is complete.

## Subtasks

- Implement ratio and standard threshold.
- Implement custom threshold.
- Implement partial-consumption fallback.
- Use inclusive equality for the recommendation.
- Calculate cost per kilometer, maximum ethanol price, and threshold difference.
- Round only in presentation.

## Expected files

- `lib/.../domain/fuel_calculator.dart`.
- `docs/architecture/domain-model.md`.

## Acceptance criteria

The calculation exactly follows the approved formulas, recommends ethanol on equality, falls back to `0.70`, and reports the rule source.

## Tests

Cover standard, custom, equality, fallback, decimal precision, and derived costs.

## Out of scope

Persistence and advanced UI.
