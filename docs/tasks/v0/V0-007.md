# V0-007 — Create the Form

## Objective

Provide the minimum input form for a calculation.

## Prerequisites

Validation and calculation domain are complete.

## Subtasks

- Add gasoline and ethanol price fields.
- Add optional consumption fields.
- Add standard/custom rule selection.
- Connect validation and numeric keyboard input.
- Make the layout responsive.

The user can enter valid values, see validation feedback, select a rule, and submit on narrow screens.

## Tests

Widget tests for fields, selection, validation, and narrow layouts.

## Out of scope
