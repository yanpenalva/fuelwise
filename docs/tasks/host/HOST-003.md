# HOST-003 — Document Network Installation

## Objective

Document installation and update through local Wi-Fi for users without ADB.

## Prerequisites

HOST-002 is working.

## Subtasks

- Connect computer and phone to the same network.
- Open the local URL.
- Download the APK.
- Allow installation from an unknown source when required.
- Install, open, and update the application.
- Document common errors.

## Expected files

- `docs/hosting/local-apk-server.md`.

## Acceptance criteria

The complete installation and update flow works through the phone browser.

## Tests

Install a new version and update an existing installation over Wi-Fi.

## Out of scope

Public distribution and app-store installation.
